# TS2MP4 v1.1.0（待发布）

作者：**Akutagawa**。自有代码采用 **MIT License**。

新增“转换成功并校验后永久删除原 TS”选项，实现批量转换后只保留 MP4。默认关闭，仅对本批次生效，开始前需要确认。

启用后，先完成转换、完整解码校验并保存 MP4，再检查原 TS 是否变化，最后删除对应原 TS。失败、取消或校验失败时保留源文件。原文件因占用或权限限制无法删除时，会保留 MP4 并显示提示。

**原 TS 将永久删除，不进入回收站。** 校验会增加处理时间；取消不会恢复前面已删除的原 TS。

两种转换模式、输出目录、多选与拖入、同名保护及失败重试继续可用。仍只保留第一路视频及全部音轨，不转换字幕和数据流。FFmpeg 需自行安装；下载包不捆绑 FFmpeg。

此版本先提供预览包验收，正式发布需确认。
