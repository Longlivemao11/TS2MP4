# TS2MP4 v1.0.2

TS2MP4 首次开源发布：一个使用本机 FFmpeg 的 Windows 桌面 TS 转 MP4 工具。

作者：**Akutagawa**。自有代码采用 **MIT License**。

## 下载

普通用户请下载 **TS2MP4-Windows-v1.0.2.zip**，完整解压后双击 **TS2MP4.exe**。备用入口为 **Start-TS2MP4.cmd**。需要 .NET Framework 4.x 和自行安装的 FFmpeg；下载包不包含 FFmpeg。

开发者可下载 **TS2MP4-Source-v1.0.2.zip**，或克隆仓库后运行 `Build-Windows.cmd`。源码下载没有预编译 EXE。

## 功能与修复

- 文件多选、拖入、批量顺序转换。
- 无损封装和 H.264 / AAC 重新编码。
- 当前 / 批量进度、输出目录选择、取消和重试。
- 同名自动编号、保留原文件、启动与转换日志。
- 修复 .NET Framework 兼容问题；保留已获 Windows 用户验证的 v1.0.2 EXE。
- 自有代码采用 MIT 许可；补齐公开文档、源码构建及集成测试入口。

## 注意事项

仅保留第一路视频及全部音轨，不转换字幕和数据流。无损模式受原编码与 MP4 兼容性限制；重新编码有损耗，需要 FFmpeg 支持 libx264 和 AAC。当前不提供自定义编码参数或硬件加速。

程序未进行代码签名。使用 `SHA256SUMS.txt` 核对下载包；SHA-256 只能检查文件一致性，不能替代可信下载来源。

此发布保留已验证二进制，并有 Linux / Mono + FFmpeg 集成验证；不代表已验证所有 Windows 和 FFmpeg 版本。详见仓库 `docs/TESTING.md`。
