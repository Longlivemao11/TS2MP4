# 使用说明

## 第一次使用

完整解压 Windows 下载包，双击 `TS2MP4.exe`。不要只从压缩包内直接运行 EXE，也不要单独搬走 `.exe.config` 或备用启动脚本所需的 `source/`。

程序会尝试寻找程序同目录、`C:\ffmpeg\bin`、PATH 或上次保存的位置中的 `ffmpeg.exe`。若未找到，点击 FFmpeg 旁边的“浏览…”选择本机文件。只需选择 `ffmpeg.exe`，不用选择安装目录。

点击“＋ 添加 TS”可多选，也可把多个 `.ts` 文件拖入列表。只接受实际存在的 TS 文件，不递归导入文件夹。相同路径只添加一次。

## 转换

1. 默认使用“快速无损（复制音视频流）”。不兼容 MP4 的源编码可能失败，可改为“重新编码（H.264 + AAC）”。
2. 勾选“保存在每个原文件旁边”，或取消勾选并选择统一输出目录。确保目录可写、磁盘空间足够。
3. 点击“开始 / 重试”。转换期间不能修改队列及转换设置。
4. 完成后点击“打开输出目录”，或双击成功的项目定位输出文件。

原文件不会被修改或删除。若 `video.mp4` 已存在，会使用 `video (1).mp4` 等名称。单项失败不会阻止后续文件转换。双击失败项目查看原因；点击“查看本次日志”可查看详细记录。

“取消批次”会终止当前转换及后续队列，保留已完成 MP4。点击“开始 / 重试”会跳过完成项，重试失败、取消和未完成项目。想让已完成文件使用另一种模式重新转换，请先移除该项，再重新添加。

进度未知时显示动态进度条。批量进度按文件数量计算，不是按视频时长或成功数计算。

## 无损与重新编码的限制

无损模式只改变封装，保持音视频编码；并非所有 TS 编码都能放进 MP4，也并非所有播放器都支持原编码。

重新编码使用 H.264、CRF 20、medium、yuv420p 和 AAC 192 kb/s。会有压缩损耗，耗时与文件大小取决于原视频。当前没有自定义码率、分辨率、硬件加速或 HDR 色调映射选项；不保证保留 HDR、色深等原视频特性。

两种模式均保留第一路视频与全部音轨，丢弃字幕和数据流。加密、损坏或特殊广播格式的 TS 不保证可以转换。

## 双击后没有窗口

1. 确认已经完整解压，目录中有 `TS2MP4.exe.config`。
2. 查看 `%LOCALAPPDATA%\TS2MP4\startup-runtime.txt`。若入口没有执行，可能不会生成该日志。
3. 双击 `Start-TS2MP4.cmd`。它使用系统 .NET Framework 4.x 编译器将源码编译到 `%LOCALAPPDATA%\TS2MP4\app-v1.0.2` 并启动，控制台会在程序关闭后退出。
4. 若失败，查看窗口及 `%LOCALAPPDATA%\TS2MP4\startup-latest.txt`，确认 .NET Framework 4.x 可用。

备用启动脚本每次都会重新编译，需要同包 `source/` 和配置文件。正常使用优先启动 EXE。下载包未进行代码签名；Windows 可能显示发布者未知的提示。请核对下载来源与 SHA-256，不要为了运行工具关闭系统保护。

## 其他常见问题

| 现象 | 检查方式 |
| --- | --- |
| 找不到 FFmpeg | 选择实际存在且名称为 `ffmpeg.exe` 的文件；在命令行运行 `ffmpeg.exe -version` |
| `Unknown encoder 'libx264'` | 当前 FFmpeg 构建缺少所需编码器，使用具备 libx264 和 AAC 的版本 |
| 无损转换失败 | 看日志中的原编码和错误，改用重新编码 |
| MP4 无法播放 | 尝试其他播放器，或重新编码后再检查 |
| 字幕消失 | 当前版本不转换字幕，可在其他工具中另行处理 |
| 输出文件找不到 | 看列表“输出文件”列；默认分别保存在每个源文件旁边 |
| 断电后出现 partial 文件 | 确认没有转换进程运行，再删除 `.ts2mp4-*.partial.mp4` |

## 日志与卸载

`%LOCALAPPDATA%\TS2MP4` 包含 `settings.xml`、`logs/`、启动诊断及备用启动生成的程序。公开报告问题时提供 Windows 版本、FFmpeg 版本、转换模式和已脱敏的错误信息。

关闭应用后，删除解压目录及上述本地数据目录即可移除工具。输出 MP4 和已安装的 FFmpeg 不会随之删除。
